Frequently Asked Questions

Which macOS versions are supported?

CoreDeck is built for macOS 13.0 (Ventura) and newer, with native ARM64 optimization for all Apple Silicon chips (M1, M2, M3, M4, Pro, Max, Ultra).

How does the VPS monitoring work without open ports?

In Mode 1 (SSH Direct), CoreDeck uses your Mac's native OpenSSH client to connect with your Hostinger or Linux panel credentials, executing a lightweight 15ms command that parses /proc. In Mode 2 (HTTP Agent), a simple 1-liner installer script sets up a systemd micro-daemon.

Is this a subscription?

No. CoreDeck is a single lifetime purchase. You buy once for $14.99 and receive a cryptographic license key usable across all your personal Macs.
