# Security Policy

## Reporting a Vulnerability

CoreDeck is a local-first native macOS Swift 6 application designed with strict zero-telemetry and OPSEC isolation.

If you discover a security issue, cryptographic license bypass, local privilege concern, or vulnerability in the CoreDeck macOS app or the optional `install_agent.sh` script, please report it responsibly rather than opening a public issue:

- **Contact:** [hello@armako.co.uk](mailto:hello@armako.co.uk) <!-- opsec-ignore -->
- **Publisher:** Armako Limited (`https://armako.co.uk/coredeck/`)
- **Legal & Privacy:** See [Privacy Policy](https://armako.co.uk/coredeck/privacy.html) and [Terms of Service](https://armako.co.uk/coredeck/terms.html)

Please include steps to reproduce, macOS version, and Apple Silicon chip details where relevant. We aim to acknowledge reports within 48 hours.
